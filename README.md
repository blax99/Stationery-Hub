# 📝 Stationery-Hub

**Stationery-Hub** is a full-stack e-commerce web application for buying stationery products online.

Users can browse products, manage their cart and wishlist, place orders, and make payments. The project also includes administrative features for managing products, categories, users, and orders.

## 🚀 Features

* User authentication and account management
* Product and category management
* Product browsing and search
* Cart and wishlist
* Order and checkout
* Payment and transaction management
* Admin management and analytics
* REST API integration

## 🛠️ Tech Stack

* **Backend:** Python, Django, Django REST Framework
* **Database:** PostgreSQL
* **Frontend:** HTML, Tailwind CSS, JavaScript
* **Tools:** Git, GitHub, Node.js, npm

## ⚙️ Quick Setup

### 1. Clone the repository

```bash
git clone <REPOSITORY-URL>
cd Stationery-Hub
```

### 2. Create and activate virtual environment

```bash
python -m venv venv
venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
npm install
```

### 4. Run the project

**Terminal 1 — Django**

```bash
python manage.py runserver
```

**Terminal 2 — Tailwind**

```bash
npm run dev
```
